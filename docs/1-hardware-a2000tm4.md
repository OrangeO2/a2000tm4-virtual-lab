# A2000TM4 硬件拆解（调试口实测版）

> 本文不是原理图转录——所有"实测"标记的数据都来自对真实板卡 ICDI 调试口的
> 现场读取（见 `tools/hwprobe/` 与 `docs/2-measured-board-facts.md`）。
> 板卡拓扑部分与《A2000TM4 电原理图 v3》一致，实测数据为本文档独有。

## 1. 系统架构

```
┌────────────────────────── A2000TM4 底板（蓝色）─────────────────────────┐
│  电源: USB/7-12V ─ AMS1117-5.0 ─ +5V ─ TPS60400 ─ −5V                   │
│  显示: TM1638 ── 8位数码管 + 8 LED + 3×3=9键（STB/CLK/DIO 三线）        │
│  蜂鸣器: PM2(有源) / PF3(无源, M0PWM3 复用)                              │
│  扩展: 扩展板A/B 各 4 针(+5V/NC/GND/−5V)，P_GND 5针接地排                │
│  U1: 4×2×10 = 80 芯核心板插座                                            │
└──────────────┬───────────────────────────────────────────────────────┘
               │ +3V3(1,21) GND(19,39,60,80) PK4(42) PK5(43) PM0(44)
               │ PM2(46) PF3(63)  ← 底板实际使用的 9 个信号脚
┌──────────────┴───────────────────────────────────────────────────────┐
│  EK-TM4C1294XL 核心板: TM4C1294NCPDT + ICDI 调试口 + 25MHz 晶振         │
└──────────────────────────────────────────────────────────────────────┘
```

**底板本身不含 MCU**：TM4C1294NCPDT 焊在插接于 80 芯插座的 LaunchPad 核心板上；
调试口、晶振、ICDI 均在核心板。底板无晶振、无复位电路、无调试口、无 DAC6571、
无 ADC 调理电路——DAC6571 在第二阶段自焊的稳流源板上，ADC 调理在成品稳压源板上，
经 J1/J2 排针接到核心板 PE2/PE3。

## 2. 主控：TM4C1294NCPDT（调试口实测确证）

| 项目 | 实测值 | 说明 |
|---|---|---|
| CPUID | `0x410FC241` | ARM Cortex-M4 r0p1（含 FPU） |
| DID0 / DID1 | `0x100A0002` / `0x101FC06E` | TM4C129-class、Tiva 家族、QFP、RoHS |
| Flash 容量 | FSIZE=`0x1FF` → 1 MB | (FSIZE+1)×2KB |
| SRAM 容量 | SSIZE=`0x3FF` → 256 KB | (SSIZE+1)×256B |
| EEPROM | EESIZE=`0x00600600` | 1536 字 = **6 KB**，96 块×16 字 |
| 调试口 | ICDI（固件版本 1224） | USB 复合设备 VID_1CBE&PID_00FD：COM 串口 + JTAG/SWD + DFU |

外设存在位（PP 寄存器实测，采样部分）：WD×2、TIMER×8、GPIO A–Q×15、DMA、EPI、
HIB、UART×8、SSI×4、I2C×10、USB。与 TM4C1294NCPDT 规格一致。

## 3. 时钟树（实测）

| 寄存器 | 实测值 |
|---|---|
| RSCLKCFG (0x400FE0B0) | `0x10000001` → USEPLL=1, PLLSRC=PIOSC, PSYSDIV=1 |
| PLLFREQ0 (0x400FE160) | `0x0080001E` → MINT=30, MFRAC=0, PLLPWR=1 |
| PLLFREQ1 (0x400FE164) | `0x00000B00` → Q 域=11 → ÷12 |
| SysTick RVR | `399999`（= 20ms @ 20MHz，与固件配置逐位吻合） |

**系统时钟 = 16 MHz PIOSC × 30 ÷ 12 ÷ 2 = 20.000000 MHz**。

25 MHz 晶振路径（MOSC）会推出 750 MHz VCO，超出 320–480 MHz 规格窗口，
被物理排除——尽管原理图画了晶振，**当前固件实际不使用它**。
同一 Q 域（5 位截断）机理可复现课程 dac_demo.c"请求 1MHz 实得 15MHz"的现象。

## 4. 显示/按键子系统（TM1638）

| 信号 | MCU 引脚 | 板上网络 | 附属 |
|---|---|---|---|
| STB | PK4 | U1.42 → TM1638.28 | 10K 上拉 + 100pF |
| DIO | PK5 | U1.43 → TM1638.26 | 10K 上拉 + 100pF |
| CLK | PM0 | U1.44 → TM1638.27 | 10K 上拉 + 100pF |

- 2 只 4 位**共阴**数码管，段码 LSB=A 段、bit7=DP；板上从左到右的数码位
  对应显示缓冲 digit[4][5][6][7][0][1][2][3]。
- 8 只 LED 正极并接 SEG9、负极接 GRID1–8（与位扫描复用），课程代码只用 LED 字节的 bit0。
- 按键 3×3 矩阵：行 K1–K3，列经 **D10–D12 二极管**回到 KS1–KS3（与 SEG1–3 复用）。
  ⚠️ 这一接法使"无键=读 0x00"的通用假设不可靠，键值解码必须按课程表
  （c[0]==0x04→键1 … c[1]==0x01→键9，见 `a2000sim/tm1638.py`）。

## 5. 电源架构（底板）

```
USB VBUS ──────┐
               ├─ S1 选择 ─ F1 保险丝 ─ +5V 轨 ─┬─ 扩展板A/B.1
7-12V ─ D1 ─ AMS1117-5.0 ───────┘               ├─ TPS60400 → −5V → 扩展板A/B.4
USB 座 P1 ─────┘                                 └─ P1 USB 座(仅供电)
+3V3 ← 核心板经 U1.1/21 馈入（专供 TM1638 与上拉）
GND：全板公共；P_GND 5 针接地排（示波器/表笔专用）
```

## 6. 引脚映射总表（课程固件实际使用）

| 外设 | 引脚 | 复用 | 备注 |
|---|---|---|---|
| TM1638 STB/CLK/DIO | PK4 / PM0 / PK5 | GPIO | 软件位拍，非 SSI |
| 有源蜂鸣器 | PM2 | GPIO | 高电平鸣叫，100Ω 限流 |
| 无源蜂鸣器 | PF3 | **M0PWM3**（实测 PCTL=6 且 RCGCPWM0 开启） | 需 PWM 输出使能 |
| ADC 输入 CH0/CH1 | PE3 / PE2 | AIN0/AIN1 | 接稳压源板 J2/J1 调理输出 |
| DAC6571 SDA/SCL | PL0 / PL1 | GPIO 软件模拟（恰为硬件 I2C2 复用脚） | 第二阶段 |
| LED4 / 按键 | PF0 / PJ0 | GPIO | exp0 验证程序用 |
| 核心板 LED D1/D2 | PN1 / PN0 | GPIO | 实测观察到翻转 |

## 7. 信号链（第一阶段稳压源 → 单片机）

```
VOUT+ ── R18/R19 分压(≈0.5) ── TLV2372 U3B 电压跟随器 ── R42+D4(Z3.3) 钳位 ── PE2
R3(0.1Ω电流采样) ── R13/R14/R15/R16 差分放大(增益10–20, +7V 供电) ── R40+D3(Z3.3) ── PE3
```

固件换算（课程 PPT 的参考标定，在 `a2000sim/plant.py` 中作为课程参考标定/理论链参数使用）：

```c
ui32OutputVol = avg × 3300/4095 × 2.005 − 1.141;   // mV
ui32OutputCur = avg × 3300/4095 × 1.002 − 36.12;   // → 电流 = mV / (增益×0.1Ω)
```
